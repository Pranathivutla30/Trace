# PhysioNet-derived data — attribution & license

The file `S12_trace_windows.csv` in this folder is a **derivative database**:
60-second window features computed by TRACE from one participant's recording in
the dataset below. No raw PhysioNet signal files are redistributed here.

## Source

Contains information from the **Wearable Device Dataset from Induced Stress and
Structured Exercise Sessions (v1.0.1)**, PhysioNet, which is made available under
the **Open Data Commons Attribution License (ODC-By) v1.0**.

- Dataset: https://doi.org/10.13026/he0v-tf17
- Citation: Hongn, A., Bosch, F., Prado, L., & Bonomini, P. (2025). *Wearable
  Device Dataset from Induced Stress and Structured Exercise Sessions*
  (version 1.0.1). PhysioNet. RRID:SCR_007345.
- Original publication: Hongn, A., Bosch, F., Prado, L. E., Ferrández, J. M., &
  Bonomini, M. P. (2025). *Wearable Physiological Signals under Acute Stress and
  Exercise Conditions.* Scientific Data, 12(1).
  https://doi.org/10.1038/s41597-025-04845-9
